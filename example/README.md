# viper_flutter example

Every kind of screen Viper has to report from: a list in its own navigator, a form with a password
field, a dialog, a bottom sheet, a drawer, tabs on an IndexedStack, an image, a web view and a
native platform view. Bundle and application ID `dev.twinsun.viper.example`.

- `lib/main.dart` is the production entry point: no Viper.
- `lib/main_staging.dart` is the only file that imports Viper's implementation (D336).

How to run it against a local Viper: the package README, "How to try it".
